\chapter{Hướng dẫn tái lập kết quả}
\label{app:repro}

Mã nguồn: \url{https://github.com/Chivu171/Multi-Agent-Crypto} (tag \texttt{eval-v1}, commit \texttt{161da6c}).
Kết quả gốc nằm tại \texttt{outputs/baselines/cryptotrade/<giai đoạn>/*/result.json}.

\paragraph{Chiến lược luật} (vài giây, không cần mô hình):
\begin{Verbatim}
python -m baselines.cryptotrade.run rules --window bull
\end{Verbatim}

\paragraph{Agent CryptoTrade} (LM Studio chạy ở cổng 1234):
\begin{Verbatim}
CRYPTOTRADE_BASE_URL=http://localhost:1234/v1 \
CRYPTOTRADE_API_KEY=lm-studio \
CRYPTOTRADE_MODEL=google/gemma-4-26b-a4b-qat \
CRYPTOTRADE_REASONING_EFFORT=none LLM_CALL_TIMEOUT=300 \
  python -m baselines.cryptotrade.run agent --window bull --variant full
\end{Verbatim}

\paragraph{Hệ thống đề xuất:}
\begin{Verbatim}
LLM_BACKEND=lmstudio LMSTUDIO_MODEL=google/gemma-4-26b-a4b-qat \
LLM_CALL_TIMEOUT=300 \
  python -m baselines.cryptotrade.run ours --window bull
\end{Verbatim}

Thay \texttt{bull} bằng \texttt{sideways} hoặc \texttt{bear} cho hai giai đoạn còn lại, hoặc bằng
\texttt{dev\_feb\_apr}, \texttt{dev\_aug\_sep}, \texttt{dev\_dec\_jan} cho tập phát triển (tag \texttt{eval-v1-dev}). Mọi
lời gọi mô hình được lưu đệm, nên chạy lại cho kết quả giống hệt mà không cần gọi lại mô hình.

\paragraph{Các cải tiến (Mục~\ref{sec:improve}).} Ba phiên bản chạy lại mô hình dùng thêm cờ
\texttt{--trend-context} (tag \texttt{eval-v2-trend}), \texttt{--debias} (tag \texttt{eval-v2-bias}) hoặc
\texttt{--debate-flip} (tag \texttt{eval-v2-debate}):
\begin{Verbatim}
python -m baselines.cryptotrade.run ours \
  --window dev_feb_apr --trend-context
\end{Verbatim}
Các cải tiến ở bước tổng hợp và phân tích tín hiệu được tính lại từ các nhận định đã lưu, mỗi bước vài giây:
\begin{Verbatim}
python scripts/trend_variants.py select     # chọn trên tập phát triển
python scripts/trend_variants.py evaluate   # một lần trên tập kiểm thử
python scripts/bias_correction.py select
python scripts/bias_correction.py evaluate
python scripts/agent_regime_analysis.py     # tín hiệu từng agent, độ bền
python scripts/significance.py              # kiểm định thống kê
python scripts/horizon_analysis.py          # tầm 1/3/7 ngày
python scripts/timing_permutation.py        # xáo trộn thứ tự lệnh
python scripts/sell_rule.py select          # rồi evaluate
python scripts/reliability_arbiter.py conflicts   # cả select,
python scripts/reliability_arbiter.py longrun     # evaluate
python scripts/arbiter_sell_rule.py
\end{Verbatim}
